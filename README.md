##  SmartCart – AI-Powered Buy & Sell Platform

SmartCart is a full-stack marketplace application that enables users to buy and sell products with the help of AI-driven recommendations and smart pricing features. The platform focuses on scalability, real-time interactions, and an intuitive user experience.

##  Features

Secure user authentication (Firebase Auth)
Buy & sell products with image uploads
AI-based product recommendations
Visual / image-based product search
Real-time buyer–seller interaction
Smart pricing suggestions using ML
Responsive and modern UI
